# Munara — прототип

Образовательная веб-платформа для подготовки детей **1–7 классов** к вступительным
экзаменам в **НИШ** (Назарбаев Интеллектуальные школы). Пять предметов:
Математика, Английский язык, Қазақ тілі, Русский язык, Естествознание.

Это **черновой прототип**: все данные локальные (моки + `localStorage`), бэкенда нет.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка (tsc + vite)
npm run typecheck
```

## Стек

React 18 + TypeScript + Vite · Tailwind CSS 3 · react-router 6 ·
lucide-react (иконки) · recharts (графики в кабинете родителя) ·
`class-variance-authority` + `tailwind-merge` — лёгкий аналог shadcn/ui.

## Демо-аккаунты

Форма входа принимает любой email/пароль. Роль выбирается кнопками
«Я ученик» / «Я родитель».

| Роль | Что открывается |
|---|---|
| Ученик · **Войти** | кабинет Амины (5 класс, streak ~20, 4 предмета) |
| Ученик · **Создать аккаунт** | онбординг: класс → предметы → вводный тест → уровень |
| Родитель · **Войти** | кабинет Динары: двое детей (Амина, Нұрислам) |

`localStorage` хранит прогресс между перезагрузками; ключ `munara.state.v1`.
План на день пересобирается при смене календарного дня.

## Модель данных — ключевые решения

Всё в `src/types/index.ts`. Спроектировано под расширение:

- **`User` — размеченное объединение по `role`** (`StudentUser` | `ParentUser`).
  Поля одной роли можно расширять, не трогая другую. Связь родитель↔дети —
  через массивы id (`parentIds` / `childIds`), т.е. many-to-many.
- **`Task` — размеченное объединение по `type`** (`single_choice`, `multi_choice`,
  `text_input`, `matching`). Новый тип задания добавляется как ещё один вариант,
  существующий код проверок расширяется через `switch` без ломки.
- **`Lesson` ↔ `Task` ↔ `DailyPlan` связаны только по id-строкам** — легко
  заменить на реальные первичные ключи БД. `Lesson.topic` совпадает с
  `WeakTopic.topic`, поэтому кабинет родителя может показывать «Требует
  внимания: Математика — дроби» и вести на нужный урок.
- **`StreakData` хранит `history: StreakDay[]`** (≈35 дней), а `current`/`longest`
  вычисляются из истории (`computeCurrentStreak`). Это делает логику
  «пропустил день → серия сгорает» детерминированной и тестируемой, а не
  завязанной на счётчик. `frozen`-день не разрывает серию — задел под платную
  «заморозку» (`freezesAvailable`).
- **Временные ряды имеют общий вид `DayValue { date, value }`** — и XP за день,
  и минуты занятий. Один компонент-график переиспользуется.
- **`DailyPlan` пересобирается на клиенте** из `selectedSubjects` +
  `weakTopics` (по одному уроку на предмет). `minItemsToKeepStreak` = дневная
  норма для сохранения серии.
- **`SubjectProgress` и `XpData` — «живые»**: `finishLesson` в сторе
  пересчитывает проценты, точность (скользящее среднее), XP и streak.
- **`PlacementResult`** отделён от `Task`: вводный тест — отдельная сущность,
  расчёт уровня (`beginner` / `core` / `advanced`) намеренно упрощён
  (доля верных ответов), чтобы показать флоу, а не адаптивный алгоритм.
- **`NotificationPrefs`** — плоский объект булевых флагов (события + каналы),
  легко маппится на будущий бэкенд настроек.

## Что дальше (для боевой версии)

- **Аутентификация и БД.** Реальные аккаунты и роли (например, Supabase /
  Firebase Auth или собственный сервис), безопасная привязка родитель↔ребёнок
  (инвайт-коды), хранение прогресса, планов и результатов в Postgres.
  Сейчас всё в `localStorage`.
- **Видеохостинг.** Загрузка и стриминг уроков (Mux / Cloudflare Stream /
  ЯндексВидео), адаптивное качество, субтитры, защита ссылок, отметка
  «досмотрено» перед практикой.
- **Генерация плана на день на сервере.** Настоящий планировщик с интервальными
  повторами и учётом слабых тем; сейчас — наивная сборка на клиенте.
- **Адаптивный вводный тест и оценка уровня.** Модель сложности заданий (IRT
  или проще), а не «доля верных ответов».
- **Платежи и подписка.** Тарифы, пробный период, оплата картой (Kaspi / Stripe /
  ЮKassa), монетизация «заморозки streak», семейные подписки на нескольких детей.
- **Push- и WhatsApp-уведомления родителям.** Реальная доставка (WhatsApp
  Business API / web-push / FCM), расписание «не позанимался к вечеру»,
  еженедельные отчёты, дайджесты по слабым темам.
- **Античит в тестах.** Пул вопросов и рандомизация, таймеры, ограничение
  повторных попыток, серверная проверка ответов (сейчас правильный ответ
  лежит в клиентских моках), детектор аномально быстрых прохождений.
- **Контент-платформа.** Админка для методистов: уроки, задания, привязка к
  классам и темам, версионирование, ревью.
- **Аналитика и наблюдаемость.** Продуктовая аналитика (retention, streak,
  воронка онбординга), Sentry, логирование.
- **Доступность и локализация.** Полный аудит a11y, переключение
  русский/қазақ интерфейса, экранные дикторы, крупный шрифт.
- **Оффлайн / PWA.** Кэш уроков и заданий для занятий без стабильного интернета.
